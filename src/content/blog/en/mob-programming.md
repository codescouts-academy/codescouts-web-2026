## **What is it?**

As mobprogramming.org says:

> "MobProgramming is: A group of bright people working on the same thing, at the same time, in the same place, in the same computer."

And as the name suggests, Mob Programming is a software development approach where the whole team works on the same thing. This is similar to pair programming, where two people sit at the same computer and work on a task or problem at the same time. One usually programs as the ‘driver’ and the other guides as the ‘navigator.’

Mob Programming is not limited to any type of work; it can be used for:

- User stories 📄
- Requirements 📃
- Testing 🧪
- Design 💄
- Bug fixing 🐛
- Problem solving 🪲

This can mean a typical mob team will design, develop, test, and deploy everything together.

## Benefits of mob programming

- Greater learning and communication 📖
- More creative capacity 💭
- Higher code quality ✅
- Happier, more cohesive team 😊

## Roles in mob programming

- Driver 🧑🏻‍💻
- Navigator 🧑🏻‍🏫

## Strong-style pairing

> "For an idea to move from your head to the computer, it must pass through another person’s hands."

> a.k.a. "don’t think about the keyboard!"

## MOB programming flow

- 10-minute timer ⏱️
- Navigator joins the mob 🧑🏻‍🏫 -> 🧑🏻‍🦱🧑🏻‍🦰🧑🏻‍🦱👱🏻🧑🏾‍🦲
- Driver becomes navigator 🧑🏻‍🏫 -> 🧑🏻‍💻

## Best practices

- Set a goal
  - Make sure the team is aligned and working toward the same objective
- Yes and...
  - Keep what you have, don’t undo previous navigators’ work
- Commit whenever you reach a safe point
  - Don’t go more than 2 minutes without committing and moving to the next step
- Trust the navigator
  - Don’t think about the keyboard
- Express your intentions to the driver
  - Write code so the next step is obvious
- Intentional code
  - Explain your intention first in plain language, then translate it into code
- Constant feedback
  - Feedback helps us know we are making progress
- Focus on learning
  - Don’t worry too much about not being productive at first

## Rules for working together

- Kindness 🧡
- Consideration 🙏
- Respect 🤝

## And how does it work remotely?

Obviously, working in the same room with the entire team feels very different, especially because of the synergy it creates.

But!! we can also work remotely, and to get a similar experience we just need a little more patience.
